# 模板

这里只保存会被复制到业务项目中的记录骨架。模板不是另一套规范；字段含义和使用时机以对应的开发、重构或测试正文为准。

```text
common/         Gate 卡片和预飞事实表
change/         收敛评审记录
development/    需求、方案、评审和验收记录
refactoring/    问题、蓝图、方案、评审和验收记录
testing/        测试计划和测试记录
```

使用时复制需要的文件，不要求每个任务创建全部模板。轻量任务可以把必要字段写进一份任务记录；标准级和高风险任务应按对应规范保留可追踪产物。

项目如果需要机器执行检查，应在业务项目中维护真实可运行的脚本和参数。本仓不保存没有执行器消费的 YAML Schema 或示意检查配置。
