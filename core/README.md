# Core：共同流程内核

Core 是 Development、Refactoring、Testing 三套流程的稳定层。它只规定共同机制，不规定具体项目用什么分支、测试环境、编程语言、模型或设备。

## 不变约束

1. **职责与人解耦**：先定义设计、实施、复核、决策等职责，再决定由谁承担。
2. **工作量与风险分级**：轻任务走轻流程，复杂或高风险任务增加方案、独立复核和 Gate。
3. **所有结论绑定事实基线**：Git 项目绑定 commit，构建产物绑定哈希，非 Git 工作绑定明确文件清单。
4. **机械检查先行，判断独立复核**：脚本负责事实表，人或独立 Agent 负责语义判断。
5. **偏差即停**：目标、接口、范围、步骤或测试对象发生实质变化时先登记、再裁决。
6. **历史不可覆盖**：修订和复测使用新版本或新轮次，保留旧结论。
7. **用户只承担不可替代的决策**：业务取舍、风险接受、最终 Gate；不要求用户重复机械核对。
8. **交接只认落盘证据**：文档、commit、diff、事实表和原始证据；聊天中的口头结论不构成交付。
