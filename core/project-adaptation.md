# 项目适配边界

[← Core](README.md)

通用规范回答“必须证明什么”，项目适配回答“在这个项目里怎样证明”。以下内容属于业务项目：

- 主线、集成、发布和功能分支命名；
- 编程语言、包管理器、格式化、静态检查、测试和构建命令；
- 开发、测试、验收和生产环境地址；
- Worktree、本机 SDK、凭据和不可提交配置；
- 模拟器、真机、数据库、第三方服务等共享资源协议；
- 架构红线、生成代码、导出符号和禁留标记；
- 发布审批人和组织内缺陷系统。

推荐项目维护 `.playbook.yaml` 声明采用版本、启用 Profile 和上述参数，同时在 `AGENTS.md` 写入人和 Agent 必须立即遵守的操作约束。

项目适配不得静默降低 Core 要求。确有例外时，按[偏差与变更协议](deviations.md)记录并由用户裁决。
