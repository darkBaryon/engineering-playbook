# 偏差与变更协议

[← Core](README.md)

执行只在已授权范围内进行。改变目标、接口、范围、步骤、测试对象或验收口径都属于偏差；漏做已批准条目同样属于偏差。

## 处理

| 级别 | 情形 | 动作 |
|---|---|---|
| 小偏差 | 实现或执行细节变化，目标和契约不变 | 登记原因与影响，提交或记录中标注，交复核确认 |
| 中偏差 | 步骤、接口、范围或验证方式变化 | 停止执行，修订受影响文档，差量复核并由用户确认 |
| 大偏差 | 目标、终态或关键假设被证伪 | 中止当前阶段，已产生成果由用户裁决，重新设计和 Gate |

“无偏差”是需要负责的事实断言，不是默认值。不得先按自己的理解做完，再补写理由。

外部环境故障也要登记：明确复现、证明它是否与代码无关、给出解除条件。未解除的强制项不能被“暂时跳过”包装成通过。
