# 分级与升档

[← Core](README.md)

分级的目的是让流程重量匹配任务，不是给任务贴重要性标签。每个 Profile 自己定义档位判据，Core 只规定定档程序和保险丝。

## 定档程序

1. 设计或测试准备职责提出档位；
2. 用一句话说明判据，不能只写“感觉复杂”；
3. 用户确认或调高档位；
4. 裁决与理由写回任务记录。

## 保险丝

- **拿不准报高一档**：信息不足或同时命中多档时，按较高流程准备。
- **越界即停升档**：执行中发现结构尺度、影响面、失败后果或验证难度超过原档位，立即停下登记并补流程。
- **只允许有证据地降档**：降档必须说明哪项风险已被事实排除，并由用户确认。
- **轻量通道不可积累规避**：多个彼此相关的小改动合起来超过轻量边界时，按整体定档。

档位阈值是经验锚点，不是绕流程的精确数学边界。
