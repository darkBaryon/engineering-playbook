# Development Profile：开发流程

[← 仓库主页](../../README.md)

适用于把新需求实现为可交付功能。它关注的是：需求是否明确、接口与数据契约是否合理、实现是否严格落在方案范围内。

开始前先遵守 [Core](../../core/README.md)。

## 一句话流程

```text
需求立案与定档 → 开发方案 → 方案复核 → Gate 1
  → 小步实施 → 预飞自检 → 代码复核 → Gate 2
  → 集成、交付、归档
```

## 状态

- 需求：`观察中 → 待计划 → 开发中 → 已交付`，另有 `已作废`；
- 方案/蓝图：`草拟中 → 待评审 → 需修改 → 已通过 → 已实施 → 已归档`；
- 评审结论：`通过 | 需修改 | 驳回`。

## 关键差异

- 起点是“要做什么”的需求，而不是结构问题或测试对象；
- 方案核心是接口、数据、模块边界、复用和验收用例；
- 预飞重点是新能力确实落地，同时无越界、调试残留或投机泛化。
