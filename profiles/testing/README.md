# Testing Profile：测试流程

[← 仓库主页](../../README.md)

适用于对一个精确的软件版本进行开发自测、独立测试、缺陷复测和发布准入。它不是“模拟器操作规范”：模拟器、真机、浏览器、API 客户端和自动化测试都只是执行平台，由项目按风险选择。

开始前先遵守 [Core](../../core/README.md)。

## 一句话流程

```text
测试立案与分级 → 固定版本/产物/环境 → Gate T0
  → 分层执行 → 缺陷修复与复测 → Gate T1
  → 业务验收 Gate T2 → 发布准入与归档
```

## 状态

```text
待测试 → 准备中 → 执行中
  ├→ 阻塞 → 准备中/执行中
  ├→ 未通过 → 修复中 → 待复测 → 执行中
  └→ 已通过 → 待业务验收 → 已验收 → 可发布 → 已归档
```

`已通过` 只表示当前精确版本的规定范围通过；`已验收` 表示业务负责人接受结果；`可发布` 仍需遵守项目自己的合并和发布规则。
