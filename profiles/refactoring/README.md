# Refactoring Profile：重构流程

[← 仓库主页](../../README.md)

适用于在保持或显式迁移既有行为的前提下调整结构、边界、依赖或公共接口。重构不允许“顺手改”；任何代码动作必须有已批准的范围和行为口径。

开始前先遵守 [Core](../../core/README.md)。

## 一句话流程

```text
问题立案与定档 → 重构蓝图/方案 → 方案复核 → Gate 1
  → 分期迁移 → 预飞与终扫 → 代码复核 → Gate 2
  → 集成、回填、归档
```

## 状态

- 问题：`观察中 → 待计划 → 执行中 → 已处理`；
- 方案/蓝图：`草拟中 → 待评审 → 需修改 → 已通过 → 已实施 → 已归档`；
- 评审结论：`通过 | 需修改 | 驳回`。

## 关键差异

- 起点是结构问题、技术债或设计缺陷；
- 方案核心是基线行为、调用方盘点、迁移路径和接口白名单；
- 预飞与终扫重点是行为不丢失、旧结构清理、无新增死代码或错误抽象。
